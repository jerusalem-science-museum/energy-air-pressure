# Energy - Air Pressure Exhibit

An interactive Python-based application developed for the Jerusalem Science Museum. This software controls or simulates an exhibit showcasing the concepts of energy transformation, air pressure, and aerodynamic forces (such as pneumatic systems, Bernoulli's principle, or pressure differentials).

## 🚀 Overview

This repository forms part of the Museum's "Energy" exhibition series. It provides the logic layer to interface with physical sensors, display real-time data visualizations to museum visitors, or manage interactive media triggered by physical air pressure inputs.

### Core Features (Typical for this exhibit)
* **Sensor Data Ingestion:** Reads input from air pressure sensors, pneumatic valves, or electronic flow meters.
* **Visitor Interface:** Displays dynamic, high-visibility visual feedback representing changes in air pressure, kinetic energy, or volume.
* **Hardware Control (Optional):** Controls physical relays or compressors to demonstrate mechanical work driven by air pressure.
* **Idle/Attract Mode:** Runs a screensaver or instructional animation when no visitor interactions are detected.
